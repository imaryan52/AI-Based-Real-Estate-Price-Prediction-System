AI-Based Real Estate Price Prediction System

Name: Thakur Aryan, Enrollment No: T2602100330023, Subject: Fundamental of Cloud Computing 

Aim: Create and deploy a simple AI model using HTML, CSS and JavaScript, hosted live on GitHub Pages.

Project: An Apartment Price Predictor that estimates the approximate property price based on location, BHK, carpet area, property type and property age.

How It Works:

  1. User searches or selects a location on the map
  2. User enters the property details
  3. The system estimates the price using a KNN-style prediction approach
  4. Estimated price, price range and confidence are displayed

Tech Stack: HTML, CSS, JavaScript, Leaflet.js, OpenStreetMap, Nominatim API

Deployment: Hosted for free on GitHub Pages. The application runs directly in the browser without a backend server.
